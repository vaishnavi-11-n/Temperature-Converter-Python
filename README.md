# 🌡️ Temperature Converter

## Overview
A desktop application developed using Python and Tkinter that converts temperatures between Celsius, Fahrenheit, and Kelvin.

This project was developed as part of the **Prodigy InfoTech Software Development Internship** to strengthen Python programming and GUI development skills.

---

## Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Input validation using exception handling
- Simple graphical user interface (GUI)

---

## Technologies Used

- Python
- Tkinter
- ttk
